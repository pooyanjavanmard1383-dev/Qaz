NYXORA - نسخه‌ی بازطراحی‌شده‌ی پخش‌کننده‌ی موزیک

تغییرات این نسخه:
- حذف صفحه‌ی آمار از منوی اصلی و جایگزینی آن با پروفایل موسیقی
- نمایش آهنگ فعلی، خواننده، آلبوم و میانبرهای علاقه‌مندی، صف پخش و اشتراک‌گذاری
- بازنویسی لیست کتابخانه برای اسکرول طبیعی و روان‌تر؛ ردیف‌ها هنگام اسکرول بازیافت نمی‌شوند
- شروع پخش با بارگذاری مجدد منبع و Resume کردن AudioContext پیش از play در Android WebView
- جایگزینی کنترل قبلی/بعدی در صفحه‌ی پخش با عقب‌گرد ۱۵ ثانیه و جلو‌بردن ۳۰ ثانیه
- تبدیل دکمه‌ی کنار مینی‌پلیر به میانبر صف پخش
- اصلاح خواندن بازه‌ای فایل صوتی در Android برای جلوگیری از پرش ناقص هنگام seek

نصب و خروجی APK:
۱) محتوای ZIP را در ریشه‌ی ریپازیتوری GitHub قرار بده.
۲) Workflow اندروید پروژه را در GitHub Actions اجرا کن.
۳) APK را از بخش Artifacts دانلود کن.
۴) بار اول مجوز دسترسی به فایل‌های صوتی را بده.

نکته: در این محیط امکان اجرای Android Gradle Build و تست روی گوشی فراهم نبود؛ کد Java و JavaScript بررسی ایستا شده و JavaScript از نظر syntax با Node بررسی شده است. حتماً APK خروجی را روی گوشی تست کن.
